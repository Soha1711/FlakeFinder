I am the **Git-Bisect subagent** for FlakeFinder. My specific role in the pipeline is to run `git bisect` over the `demo-repo` commit history to pinpoint which commit **introduced a flaky test**, using repeated test runs to classify each commit as good or bad.

### My Script: [`agents/scripts/git_bisect_runner.sh`](agents/scripts/git_bisect_runner.sh)

**What it does:**
| Concept | Detail |
|---|---|
| **Input** | `<test_path::test_name>` `<N>` `<failure_threshold>` |
| **Known good anchor** | Parent of commit `04805c1` (hardcoded) |
| **Known bad** | `HEAD` of `demo-repo` |
| **Classification** | Runs the target test `N` times per commit; if failures ≥ threshold → `git bisect bad`, else → `git bisect good` |
| **Output** | Final bisect log showing the first bad commit |
| **Cleanup** | Calls `git bisect reset` after finding the culprit |

**Example invocation (from the Step 6 measurement procedure):**
```bash

```
